## Server Connection Details

- **Local API Base URL**: `http://localhost:8001/api/v1`
- **Network / LAN Base URL**: `http://<server-ip>:8001/api/v1`
- **Interactive Swagger UI**: `http://localhost:8001/docs`
- **CORS Policy**: Pre-configured with `Access-Control-Allow-Origin: *`. Frontends can connect from any web host or mobile device without CORS errors.
